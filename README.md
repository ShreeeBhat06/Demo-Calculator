# Demo Calculator

A simple web-based calculator built using Java Servlet and JSP as part of learning Java EE web development.

## Features

- Add, subtract, multiply and divide two numbers
- Result displayed on the same page
- Clean and simple UI using HTML and CSS

## Tech Stack

- Java Servlet
- JSP (JavaServer Pages)
- HTML + CSS
- Apache Tomcat 10.x

## Notes

- Built with Tomcat 10 so imports use jakarta.servlet not javax.servlet
- This is a beginner project made while learning Java web development
